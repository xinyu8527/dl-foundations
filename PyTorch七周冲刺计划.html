00你给的原文，改掉了我三个判断

这三处不认，计划就是错的。先说我原来错在哪。

① 项目形态：不是「1–2 个大项目」

原计划：4 周做一个 CIFAR-10 大项目 → 原文是「预计 1 至 2 个月内，每周需完成 1 至 2 个简单的 PyTorch 实践项目」。考的是熟练度，不是你做了多复杂的模型。7 周对应 10–14 个小项目，每个 2–4 小时，跑通即算，不写长报告。

② 论文复现进了 12 月底的交付物，不是「之后」

原计划：论文复现放到寒假 → 原文是「基础实践与论文复现（12 月底前）……独立完成经典论文复现，严禁直接复制代码或依赖大模型生成」。复现必须吃掉 W4–W7，这是整份计划里权重最高的一件事。

③ SVM 不能跳过

原计划：《统计学习方法》7 周内别碰 → 原文的深度学习基础明确列了「反向传播、CNN、DNN、SVM」。SVM 要花 3–4 小时把思想讲清（最大间隔、支持向量、核技巧），配一个 sklearn 小实验。但仍然不做公式推导，也不通读李航。

反过来：GAN / VAE / Transformer 不在导师列的四项里，从必做移到选做，省下的时间给复现。

05论文复现：怎么算「独立完成」

导师的红线是「严禁直接复制代码或依赖大模型生成」。这条红线具体落在哪，得说清楚，否则你会不自觉地越线。

可以

  • 读论文原文，逐段做笔记
  • 看 《动手学深度学习》 的文字讲解理解原理（只看文字，不看它的代码块）
  • 查 PyTorch 官方文档的 API 签名和参数含义
  • 看报错信息，自己搜索错误原因

不可以

  • 开着别人的 .ipynb 边看边敲
  • 让大模型生成模型定义、训练循环
  • 直接 clone 开源实现然后改超参
  • 复制粘贴后「看懂了」就当自己写的
步骤做法
1 选论文首选 ResNet（CIFAR-10 版，ResNet20）。结构简单、指标明确、8GB 够跑。备选 VGG11，降级 LeNet-5。
2 读三遍一遍通读抓结论 → 二遍只看方法章记结构 → 三遍对着图表画自己的结构草图。
3 纸上设计合上所有资料，写清每层的输入输出维度、残差怎么加、下采样在哪。这一步写不出来就别开电脑。
4 手敲先写模型，用随机张量测前向形状；再写训练循环；最后接数据。
5 对齐先跑通短训练看 loss 会不会降，再对照论文的超参表逐项设置。
6 自证GitHub 分次 commit（「实现 BasicBlock 前向」「加入学习率衰减」），配一份实验日志。这比任何解释都有说服力。

为什么不能只看书

验收标准不是「读完了」

导师考的是每周 1–2 个小项目 + 独立复现。书读完但代码写不出来 = 0；反过来代码跑通但讲不清原理，20 分钟组会也过不了。

为什么也不能只看视频

视频会骗你以为懂了

视频跳过「为什么」，跟着敲能跑但说不出原因。《深度学习入门》第 4、5 章的推导就是补这个——导师要的反向传播理解深度，只能从这里来。

一个诚实的提醒

《Learning Python（第 6 版）》有 1600 页，通读要三个月，其中八成内容和这次任务无关。而且读它是最「像在学习」的逃避方式——翻书有进度感，debug 没有。如果你某天发现自己宁愿读 Python 语法也不想打开报错的代码，那不是勤奋，是在躲。W1 到 W7 都不要碰它的正文章节。

08五条避坑

  1. 视频看完 ≠ 学会。规则：看一集 → 关视频 → 凭记忆重写 → 跑通 → 才点下一集。边看边抄是这七周最容易掉进去的坑。
  2. 8GB 显存的红线。CIFAR + ResNet 的 batch 别超 64；OOM 就降 batch 或开 torch.amp；不要一上来试 256。
  3. 《统计学习方法（第 2 版）》只读 SVM 那一章的两节。其余章节（感知机、EM、HMM、CRF）这七周不碰，寒假再说。《Learning Python（第 6 版）》和《Python编程：从入门到实践（第 3 版）》当字典查，别线性读。
